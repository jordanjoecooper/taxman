    For people & agents

    The same calculation engine powers this page and a dependency-free Node interface. It accepts structured inputs and returns the calculation, tax bands, assumptions and warnings.

    Taxman.calculate({
  year: '2026/27', country: 'scotland',
  income: 60000,
  pensionMethod: 'salary-sacrifice',
  pension: 6000, studentPlans: ['4']
})

    Use Taxman.compare(baseline, changes) for scenarios. Download the distribution to use node cli.cjs < input.json. The full JSON result is also in #taxman-result after each calculation.
